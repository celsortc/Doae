# Plataforma de Doações

Plataforma desenvolvida para facilitar a **doação e reutilização de roupas**, conectando pessoas que possuem roupas para doar com instituições e ONGs que podem destiná-las a quem precisa.

## Funcionalidades

### Usuário

* Cadastro
* Login
* Cadastro de roupas para doação
* Visualização das ONGs
* Visualização das solicitações/interesses das ONGs
* Aceitar ou recusar uma doação

### Instituição / ONG

* Login
* Cadastro previamente autorizado
* Visualização de roupas disponíveis
* Demonstrar interesse em uma roupa
* Visualização das informações da doação

## Fluxo básico

1. Usuário realiza o cadastro.
2. Usuário cadastra uma roupa para doação.
3. Uma ONG autorizada acessa a plataforma.
4. A ONG visualiza as roupas disponíveis.
5. A ONG demonstra interesse em uma roupa.
6. O usuário recebe a solicitação.
7. O usuário aceita ou recusa a doação.
8. Em caso de aceite, são apresentadas as informações da ONG e uma breve descrição.
